- RNF-01: Usar Python e evitar dependências desnecessárias.
- RNF-02: Tratar entradas inválidas quando solicitado.
- RNF-03: Manter cada atividade isolada e identificável.

Os requisitos detalhados são os enunciados originais do README; este arquivo não redefine as fórmulas.
